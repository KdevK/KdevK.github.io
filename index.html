GO PROJECT · АСИНХРОННАЯ ОЧЕРЕДЬ ЗАДАЧ

Распределённая система обработки задач, разработанная с нуля на Go — без Celery, Sidekiq и готовых queue-фреймворков.

  • API Server — REST + gRPC, сохранение в PostgreSQL и публикация задач в брокер.
  • Broker — собственная in-memory реализация с последующей интеграцией Kafka для надёжной доставки.
  • Worker Pool — конкурентный пул goroutine с семафором для контроля нагрузки и зарегистрированными обработчиками.
  • Observability — метрики Prometheus и distributed tracing через OpenTelemetry.
